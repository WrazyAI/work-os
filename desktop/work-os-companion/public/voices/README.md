# The voices Otto reads recaps in

Four clips, one sentence each, generated with `google/gemini-3.8-flash-tts` on fal
through the app's own speech module on 2026-10-16, then transcoded to mono 96kbps
MP3. They are shipped as static assets so auditioning a voice costs nothing and
never depends on the network; the recaps themselves are synthesised on demand.

The employee sees our names, never the provider's:

| Shipped file | Our name | Provider voice |
| ------------ | -------- | -------------- |
| `warm.mp3`   | Warm     | Kore           |
| `calm.mp3`   | Calm     | Charon         |
| `bright.mp3` | Bright   | Leda           |
| `deep.mp3`   | Deep     | Iapetus        |
